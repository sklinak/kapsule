# 🍑 Капсула питания

Личное веб-приложение для мягкого набора веса: считает норму КБЖУ, помогает собрать рацион на день из «капсулы» простых и модных белковых блюд и радуется вместе со мной, когда норма добрана.

## Что умеет

- **Норма КБЖУ** по формуле Миффлина–Сан Жеора с учётом активности и профицита на набор
- **Плавный старт**: норма повышается постепенно, без резкого скачка калорий
- **Мой день**: 3 основных приёма пищи + перекусы, кольцо калорий и полоски БЖУ
- **«Добери меня»**: калорийные бустеры, когда до нормы осталось чуть-чуть
- **Капсула из 49 блюд**: базовые, трендовые, перекусы и смузи; поиск, фильтры, избранное
- **«Собрать день за меня»**: автоподбор блюд под норму
- **Прогресс**: график веса, серии дней и достижения
- Светлая и тёмная тема, работает офлайн, ставится на телефон как приложение

## Как пользоваться

Открыть сайт на GitHub Pages → в Safari нажать «Поделиться» → «На экран „Домой“».

Все данные хранятся только в браузере на устройстве и никуда не отправляются. Резервную копию можно скачать в разделе «Профиль».

## Устройство

Чистые HTML, CSS и JavaScript, без фреймворков и сборки.

| Файл | Что внутри |
|---|---|
| `index.html` | разметка экранов |
| `style.css` | дизайн и темы |
| `app.js` | логика: расчёт нормы, дневник, прогресс |
| `recipes.js` | база рецептов (КБЖУ на порцию) |
| `manifest.json`, `sw.js`, `icons/` | установка на телефон и офлайн-режим |

Чтобы добавить или изменить блюдо, достаточно поправить `recipes.js`.
